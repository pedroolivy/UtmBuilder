# 🧠 Aplicando Orientação a Objetos em Projetos Reais com C# 11 e .NET 7

Este repositório contém os estudos, exemplos e práticas desenvolvidas durante o curso **"Aplicando Orientação a Objetos em Projetos Reais com C# 11 e .NET 7"** ministrado por **André Baltieri (Balta.io)**.

> 🚀 O objetivo do curso é aplicar conceitos modernos de orientação a objetos em um **cenário de projeto real**, resolvendo problemas típicos da programação do dia a dia com foco em **legibilidade, encapsulamento, boas práticas e testes**.

---

## 📚 Conteúdo Abordado

- Conceitos avançados de **Orientação a Objetos**:
  - Abstração, Encapsulamento, Herança e Polimorfismo
  - Imutabilidade, composição e uso de métodos de extensão (Extension Methods)
  - Uso apropriado de Exceptions no domínio

- Boas práticas com **C# 11** e **.NET 7**:
  - Organização de código orientada a domínio
  - Uso de readonly e encapsulamento correto

- Testes de unidade com foco em **regra de negócio**, validando cenários reais
- Construção de uma **mini biblioteca de contratos**, aplicando o paradigma OOP
- Organização do projeto utilizando padrões modernos

---

## 🧪 Tecnologias Utilizadas

- C# 11
- .NET 7
- xUnit / NUnit (dependendo do setup dos testes)
- Git e GitHub
- Visual Studio / Rider

## ✅ O que eu aprendi

- A importância de aplicar OOP com **foco no problema**, e não apenas na teoria
- Como escrever código limpo, reutilizável e de fácil manutenção
- Como **encapsular regras** no próprio domínio ao invés de espalhá-las em serviços
- Como **testar comportamentos reais**, e não apenas linhas de código
